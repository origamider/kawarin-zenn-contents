# はじめに
.zshrcファイルをいじる際、
```
nano ~/.zshrc
```
のようにnanoエディタを使ってターミナル内で修正することが多いです。
自分はあまりnanoとかvimとか慣れていなかったので、今回はとりあえずnanoの「これだけ押さえておけばなんとかなる」コマンドを3つ記載しました。

# 基本コマンド
|コマンド|意味|
|------|----|
|nano [ファイル名]|指定したファイルを開く(なければ新規作成)|
|Ctrl + X|nano終了。(ここでSaveが聞かれるのでEnterでSaveできる)|
|Ctrl + W|単語検索。WはWordの頭文字。|
