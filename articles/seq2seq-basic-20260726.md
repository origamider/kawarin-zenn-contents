# はじめに
「ゼロから作るDeep Learning 2」でseq2seqを学んだので、学習用に書こうと思いました。

# seq2seqとは
そもそも初見で見たとき、seq2seqってどういうことと思ったが、
「sequence to sequence」、つまり時系列データから別の時系列データへ変換するモデルのことを指すらしい。
時系列データは順序のあるデータで、文章や動画、画像、株価の推移などがあるね。

# 実際に学習してみた
ぜろつく2に従って、実際に足し算データを学習させる。
addition.txtとしてデータが格納されており、全部で50000行。
データの中身は下記の通り。
![](/images/article-2/image1.png)

データの形状だが、桁数によって入力、出力の大きさが変わってしまいます。
例を挙げるなら、
- 12 + 21 = 33
- 121 + 212 = 333

の2パターンがある場合、前者が入力5個,出力2個で、後者が入力7個,出力3個で、大きさが変わる。
これを統一するために、空白を導入することで、大きさを統一できる。
イメージは以下。
![](/images/article-2/image2.png)
ただ、これだと空白の部分が損失に影響しないようにする必要があり、実装がだるい。(空白は足し算の間違いに影響しないよね)
今回は一旦、空白処理はせずに進めます。

コードについては、ほとんどぜろつく2を参考にしたので、[公式ソースコード](https://github.com/oreilly-japan/deep-learning-from-scratch-2/tree/master)を参考にしてね。

結果はこちら。
![](/images/article-2/image3.png)
精度が思ったより低くて残念。
ただ、この後、ある工夫をすると、精度がとても上がるらしい。
