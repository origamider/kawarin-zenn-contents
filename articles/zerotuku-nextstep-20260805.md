# はじめに
ある程度ぜろつくシリーズを触った私が、次に機械学習エンジニアとしての市場価値を上げるために何をするべきかを自分なりに考えてみました。

# 対象読者
- 「ゼロから作るDeep Learning」シリーズをある程度触っている人
- 機械学習エンジニアとしての市場価値を上げるためのネクストステップを考えている人

# 追記
私は執筆時点で機械学習の専門家でもエンジニアでもありません。
そのためあくまで、ぴよぴよの考えとして捉えてください。

# 何をするべきか
私は、すでにぜろつく1,2,4を触っています。
逆誤差伝播法の仕組み、活性化関数(Softmax,ReLU等)、最適化関数(Adam,SGD)、自然言語処理の基礎(RNN,LSTM,Attention)、強化学習の基礎(Q-learning,DQN,モンテカルロ法,SARSA)等などならなんとなくわかります。
その上で、今回は機械学習エンジニアとしての市場価値を上げるために何をするべきかを考えたいのです。

結論としては、
- PyTorch,Keras等の深層学習ライブラリで色んなprojectを試してみる
- MLOpsをかじってみる
だと考えています。

## PyTorchを使ったProjectをやってみる
実際に機械学習エンジニアとしてやっていくためには、既存のライブラリをどんどん使えるようにするべきだと思っています。
ぜろつくシリーズでNumpyベースのフルスクラッチ実装経験をしたことで、当初はブラックボックスだった機械学習の仕組みがある程度クリアになっていると思われます。
ただ、実際に働くことになった場合、基本的にはスクラッチで実装するよりも、既存のライブラリを駆使しながら機械学習の技術を取り入れるケースが多いと想定しています。
ですので、例えばですが、
- PyTorchで日本語から英語への翻訳モデルを構築する
- レコメンドシステムを構築する
などが挙げられます。

## MLOpsをかじる
実際にモデルが構築できたとしても、それをサービスに取り込む方法や学習済みモデルのperformanceの監視をする方法など、機械学習モデルの運用・保守も必要です。
興味があるのであれば、実際に触ってみると良いかもしれません。MLOpsはインフラ周りの知識も求められると思うので、市場価値が高いと思われます。(従来のDevOps的な立ち位置)

私が最近興味を持ったのは、DataTalks.Clubが提供するMLOps Zoomcampです。
MLOpsの基本的な知識を実際に手を動かしながら学べるハンズオン形式の無料サービスです。
YouTubeにlecture動画がたくさんあります。
今後、触っていきたいと思っています。
https://github.com/DataTalksClub/mlops-zoomcamp/tree/main
